# Testing Plan
*(Planned test cases for implementation phase)*
* Student registration and login flows.
* Club joining and duplicate membership prevention.
* Event creation and deadline validation.
* Event registration capacity checks and duplicate registration prevention.
* Attendance marking and feedback submission (duplicate feedback prevention).
* Role restrictions (students cannot access admin panels).
* Database constraints (invalid emails, negative capacities).
* Referential integrity (deleting a club affects events).
